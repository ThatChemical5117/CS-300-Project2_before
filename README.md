# CSC-300 Journal reflection

The problem that I was solving with this project, was using efficient data structures to store, sort, and find information that war requested by the user.
In this case it took the form of a course advising program, where course information was the data I needed to store. Knowing and understanding different data structures
enables a programmer to find the best tools to solve a given problem or task. I approached the problem, with the help of my pseudo code, in sections. Creating the high level functions first,
then filling in the details as I went. One road block that I had was when I was implementing a hash table. The hash table implementation I created for this project did not work correctly.
And I couldn't figure out why. Instead I used the hash table that I wrote for the bid assignment, since that was a known working implementation and changed it to work with course objects.
Often times in previous assignments, because they were smaller, I would just start coding something without much planning and that worked fine. But for this project it would have been much more difficult to do that
because of the many moving parts of the program. Rather my pseudo code, provided a great template to guide what I needed to do, and what features, functions, and data structures I would need to make the program work.
I could then focus on hammering out the small bugs and other issues rather than be bogged down by the big picture, since that was all planned out. Planning out the code first also allowed me to write more flexible code.
This change means I can better organize and maintain the codebase since it is all preplanned rather than written in haste.
